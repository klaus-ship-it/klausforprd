# VIP 機制規格書 V3

版本：v3.0-draft
時間基準：系統時間
適用範圍：營運後台 VIP 等級設定、每日升級、每月保級／降級、人工調整與異動查詢。

## 1. 本版決策

1. 升級每日 00:00:00 執行；保級與降級每月 1 日 00:00:00 執行，均依系統時間。
2. 升級判定使用目標 VIP 等級的「歷史總儲值」與「當月總投注額」；已配置的綁定資料條件仍須一併符合。
3. 若當次未達升級條件，於每月 1 日結算前一完整月份的保級條件。保級使用「當月儲值金額」、「當月投注額」與可啟用的「當月活躍天數」；所有已啟用條件均達標則維持目前等級，任一未達標則降級。
4. 會員被降級後，後續升級不再使用恢復專用的月保級條件；重新依一般升級條件（歷史總儲值＋當月總投注額＋已配置綁定條件）判定。
5. 系統不預設 VIP0～VIP15 的營運設定。VIP0 為系統固定基礎等級；VIP1 以上由營運新增，新增數量不設上限。新建等級預設停用，設定完成後才可啟用。
6. 移除 VIP 投注返水設定欄位、數值表與原型輸入介面。本版不再維護或顯示該欄位。
7. 「歷史最高 VIP」保留為後台顯示與歷史查詢欄位，不參與升級、保級、降級、恢復或獎勵判斷。人工調整仍保留「保存／不保存／取消」選項；保存只更新顯示資料。
8. 待結算月份曾升級的會員，該月 1 日結算不得因保級條件不足而降級，紀錄異動結果為「當月升級不降級」。

## 2. 每日／月度排程決策流程

每日 00:00:00 執行升級；每月 1 日 00:00:00 另執行保級／降級，均依系統時間。同一會員同一次月度結算只產生一個最終 VIP 結果；若兩排程同時發生，先完成保級／降級，再依結算後狀態判斷升級：

1. 讀取會員目前 VIP、歷史總儲值、當月總投注額、當月儲值金額及目前等級設定。
2. 由目前等級往上檢查已啟用的下一個 VIP 等級；目標等級所有已配置的歷史總儲值、當月總投注額與綁定條件均符合時升級。若連續多級符合，可直接升至最高符合等級，並逐級處理尚未領取的升級獎勵。
3. 每月 1 日結算先檢查待結算月份是否曾升級；若曾升級，維持目前 VIP 並記錄「當月升級不降級」。未符合此條件時，再檢查目前 VIP 的保級開關與前一完整月份條件：
   - 無條件保級：維持目前 VIP。
   - 當月儲值、當月投注額與所有已啟用的活躍天數條件均達標：保級成功，維持目前 VIP。
   - 任一條件未達標：每次最多下降 1 級；連續降級達全域 N（1～15）後，維持目前 VIP並記錄「已達連續降級上限」。
4. 被降級會員之後再次達到一般升級條件時，依一般升級流程升級，不使用恢復專用條件。
5. 同一排程不得同時產生升級與降級；若先判定升級，當次不再執行保級／降級。
6. 人工調整選擇「當月保級」時，當次排程不因保級條件未達標而降級；「當月不保級」則照正常流程判定。同一會員同一自然月不得重複建立人工保級判定。

## 3. VIP 等級設定

### 3.1 營運新增

- VIP0 固定存在且不可刪除；VIP1 以上由營運新增。
- 新增等級編號使用目前最大編號加 1，無新增上限且不可重複。
- 新增完成後狀態固定為停用；營運完成名稱、圖示、條件、獎勵與權益設定後，才可手動啟用。
- 啟用等級的升級與保級條件不得低於上一個已存在等級；可等於或高於上一級。

### 3.2 條件欄位

| 欄位 | 規則 |
|---|---|
| 歷史總儲值 | 選填；用於升級判定 |
| 當月總投注額（晉級） | 選填；用於升級判定 |
| 綁定資料門檻 | 無／手機號碼／信箱／手機號碼＋信箱；與其他已配置升級條件採 AND |
| 保級開關 | 開啟時檢查已啟用的當月儲值、當月投注額與活躍天數；關閉時為無條件保級 |
| 當月儲值金額（保級） | 保級開關開啟時使用 |
| 當月投注額（保級） | 保級開關開啟時使用 |
| 當月活躍天數（保級） | 保級開關開啟且條件啟用時使用 |
| 連續降級上限 N | 全域設定，合法範圍 1～15 |
| P2P 贈禮手續費 | 沿用既有權益欄位；本版不改計算行為 |

## 4. 人工調整

人工調整 VIP 等級時必填異動原因，並依序確認：

1. 歷史最高 VIP：保存／不保存／取消。此選項只影響顯示資料，不影響任何判定。
2. 升級獎勵：發放／不發放升級／取消。選擇發放時，目標範圍內尚未領取的獎勵逐級發放，已領取者不得重複發放。
3. 當月保級：當月保級／當月不保級。當月保級只對本自然月有效。

## 5. 異動紀錄

每次每日排程、每月結算、人工保級、人工調整與升降級均保留完整紀錄，至少包含會員、前後 VIP、判定時間（系統時間）、觸發原因、歷史總儲值、當月總投注額、當月儲值、當月活躍天數、適用門檻、N、連續降級月數、當月升級不降級狀態、獎勵結果、歷史最高同步選項與操作來源。

獎勵結果使用中文：已發放、不發放、已領取不重發、降級／保級不適用升級獎勵。

## 6. 原型範圍

- VIP 設定頁顯示每日升級與每月 1 日保級／降級排程，時間依系統時間。
- VIP 設定頁不預先列出 VIP1～VIP15；僅顯示固定 VIP0 與營運已新增的等級。
- 新增 VIP 預設停用，按鈕依狀態切換為啟用／停用。
- 條件設定改為歷史總儲值、當月總投注額（晉級）、當月儲值、當月投注額及當月活躍天數（保級）。
- 移除投注返水欄位與所有相關顯示。
- 保留會員人工調整的歷史最高同步選項，但明確標示為顯示資料用途。
